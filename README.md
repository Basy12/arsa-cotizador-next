# ARSA Cotizador Next v1.0

Cotizador comercial de telecomunicaciones AT&T con arquitectura modular, UI Crystal Glass y exportacion visual.

## ✨ Caracteristicas

- ✅ **Motor Comercial Completo**: Promociones, Titanio, portabilidad, seguro, control
- ✅ **Importador Excel**: Lee archivos XLSX/XLSM de AT&T Premium
- ✅ **Catalogo Inteligente**: Busqueda, filtrado por marca, seleccion de equipos
- ✅ **Persistencia Local**: Guarda catalogo y estado del formulario
- ✅ **Theme Engine**: 9 planes con colores y rentas base
- ✅ **Crystal UI**: Diseño VisionOS / Liquid Glass responsive
- ✅ **Cliente**: Nombre y telefono del cliente
- ✅ **Operaciones**: Renovacion, linea nueva, portabilidad, etc.
- ✅ **Comparativa**: Ahorro total y descuento porcentual
- ✅ **Exportacion Visual**: PNG y PDF con apariencia completa
